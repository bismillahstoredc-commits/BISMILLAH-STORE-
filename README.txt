Bismillah Store Desktop
========================

এই ফোল্ডারে যা আছে:
- BismillahStore.html         -> মূল অ্যাপ (মোবাইল নাম্বার + পাসওয়ার্ড লগইন সহ)
- Run_BismillahStore.bat      -> এক ক্লিকে অ্যাপ খোলার লঞ্চার (App Mode, কোনো URL bar থাকে না)
- Create_Desktop_Shortcut.bat -> ডেস্কটপে কাস্টম আইকনসহ শর্টকাট বানানোর টুল (একবারই চালাতে হবে)
- create_shortcut.ps1         -> Create_Desktop_Shortcut.bat এর সাহায্যকারী স্ক্রিপ্ট (এটাতে হাত দেবেন না)
- icon.ico                    -> অ্যাপ আইকন

সবচেয়ে ভালো উপায় (একবারই করতে হবে):
--------------------------------------
1. "Create_Desktop_Shortcut.bat" এ ডাবল-ক্লিক করুন
2. Windows "Unknown Publisher" সতর্কতা দিলে "More info" -> "Run anyway" চাপুন
3. এটি স্বয়ংক্রিয়ভাবে Desktop-এ "Bismillah Store" নামে একটি আইকন বানিয়ে দেবে
4. এরপর থেকে শুধু ওই Desktop আইকনে ডাবল-ক্লিক করলেই অ্যাপ সরাসরি App Mode-এ
   (ব্রাউজারের কোনো address bar/ট্যাব ছাড়া, একদম সত্যিকারের সফটওয়্যারের মতো) খুলবে।

দ্রুত/সরাসরি চালাতে চাইলে:
---------------------------
"Run_BismillahStore.bat" এ ডাবল-ক্লিক করলেই অ্যাপ App Mode-এ খুলবে (শর্টকাট ছাড়াই)।

শর্তাবলী:
---------
- Run_BismillahStore.bat এবং Create_Desktop_Shortcut.bat/create_shortcut.ps1/icon.ico
  সবসময় BismillahStore.html এর একই ফোল্ডারে রাখতে হবে (ফোল্ডার সরালে/নাম বদলালে
  Desktop শর্টকাট আবার নতুন করে বানাতে হবে)।
- Microsoft Edge অথবা Google Chrome ইনস্টল থাকা লাগবে (দুটোর একটাও না থাকলে
  ডিফল্ট ব্রাউজারে সাধারণ ট্যাব হিসেবে খুলবে)।
- প্রথমবার অ্যাপ খুলে মোবাইল নাম্বার + পাসওয়ার্ড দিয়ে লগইন/অ্যাকাউন্ট তৈরি করুন —
  একই নাম্বার+পাসওয়ার্ড মোবাইলেও ব্যবহার করলে ডেটা সব জায়গায় মিলে যাবে।
